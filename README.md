# カメラ辞書

本や紙に印刷された文字を **スマホのカメラで撮って、そのまま辞書で調べる** アプリです。
撮った1行を単語に区切って読みがなを付けて並べるので、知りたいことばをタップするだけで意味が出ます。

**公開URL: https://ksa02g.github.io/DictionaryCam/**
（MyApps の `camera-jisho/` を、push のたびに `ksa02g/DictionaryCam` へミラーしています）

- 本体は **`index.html` 1つだけ**（ビルド不要）
  ※ 同梱の `apple-touch-icon.png` と `manifest.json` は、ホーム画面に追加したときのアイコン用です。
  `ndl-chars.json` は文字の読み取り（NDLOCR-Lite）の文字の一覧です
- カメラは **https のページ**（GitHub Pages など）か `localhost` でしか使えません
- 写真は **端末の中だけで読み取ります**。外へ送るのは「調べることば」だけです（Wikimedia の API へ）
- 履歴・ブックマーク・設定は端末のブラウザ（localStorage）にだけ保存します

## 使いかた

1. 上で辞書を選ぶ（**国語・漢字** / **英和・和英** / **Wiki**）
2. 「スキャン」で、読みたい行の **先頭の文字を赤い矢印に合わせ**、行が **点線のあいだ** に入るように撮る
   - 縦書き・横書きは右上のボタンで切り替え（辞書ごとに覚えます。最初は国語と Wiki が縦書き、英和が横書き）
   - 文字が点線からはみ出すときや小さすぎるときは、 − ＋ で大きさを合わせる
   - 左下のボタンで **写真から** も読み取れます（写真は指で動かす・2本指で拡大縮小）
   - ライトのボタンは、ブラウザがライトに対応しているときだけ出ます（iPhone の Safari では出ません）
3. 下に出た単語をタップすると辞書の画面へ
   - 「読み取った文字」は1字ずつタップして選べます。1字目をタップしてから2字目をタップすると、そのあいだを選びます
     （なぞっても選べる。選んだ1字をもう一度タップか × でやめる）。選ぶと **「〜」を Google で検索** のボタンが出て、
     選んだ文字をそのまま Google で検索します（区切りがずれたことばや、何字かまとめて調べたいときに）
   - 端の「読んだ範囲」は、点線のあいだを切り出した、**実際に読み取った画像** です（タップで大きく見られる）。
     シートに隠れる帯の下のほうに何が写っていたか、1行が帯に収まっていたか、ぼけていないかを確かめられます
   - 「漢字のみ」で、漢字を含むことばだけに絞れる
   - 活用している語は基本の形で引きます（「読ん」→「読む」）
   - 読み取った文字を直す機能はありません（読み違えたときは撮り直すか、辞書の画面の欄に入力する）
4. 辞書の画面
   - 下の列で、撮った行のほかの単語に切り替えられる。いちばん下の欄に入力して調べることもできる
   - 上で辞書を切り替えると、同じことばをその辞書で引き直す
   - しおり（ブックマーク）・共有・文字サイズ（小・中・大・最大）
   - 「ほかで調べる」で、同じことばを **コトバンク・Weblio**（英和・和英では Weblio 英和・和英）や Google で開く
   - 辞書に見つからないときは、**「〜」を Google で検索** の大きなボタンを出す
   - 共有するリンクは `…/#q=ことば&d=ja` の形で、開くとそのことばを引いた画面になります
5. 「履歴」で、調べたことば（新しい順・300語まで）とブックマーク

## 辞書のデータ

どれも Wikimedia の公開 API から、調べるたびに取得します（キー不要・無料。内容は **CC BY-SA 4.0**、画面の下に出典を出しています）。

| 辞書 | 調べる所 |
|---|---|
| 国語・漢字 | ウィクショナリー日本語版の「日本語」の項。1字の漢字は「漢字」の項から音読み・訓読み・部首・画数・意義も出す。「〜を参照」「〜の漢字表記」とだけある項目は参照先も続けて出す。項目がなければ Wikipedia の冒頭 |
| 英和・和英 | 英語のことば → ウィクショナリー日本語版の「英語」の項（複数形・過去形などは元の形も試す。変化形しか載っていなければ元の形の項目も出す）。なければ英語版の説明（英英）。日本語のことば → ウィクショナリー英語版の「Japanese」の項 |
| Wiki | Wikipedia 日本語版の冒頭（英語のことばで日本語版がなければ英語版）。題が一致しなければ検索結果 |

ウィクショナリーは市販の国語辞典ほど語数が多くないので、載っていないことばもあります（例「下学」は中国語の項目だけ、「雑話」は項目なし）。
そのときは「見つかりませんでした」の下に、**Google で検索** の大きなボタン（国語は「ことば 意味」、和英は「ことば 英語」で検索）と
「分けて調べる」の候補を出します。国語で Wikipedia の説明を代わりに出したときも、同じボタンを出します。
見つかったときの「ほかで調べる」には、コトバンク（デジタル大辞泉・日本国語大辞典など）と Weblio も出します。
どちらも内容はアプリに取り込めない（ブラウザから読み出せず、規約上も）ので、そのことばのページを開くだけです。
コトバンクは載っていない語だと直接のページが 404 になるので、検索のページを開きます。

## しくみ

| 役目 | 使っているもの | 読み込み |
|---|---|---|
| 文字の読み取り（OCR） | 国立国会図書館の [NDLOCR-Lite](https://github.com/ndl-lab/ndlocr-lite)（**CC BY 4.0**）の文字列認識モデル（PARSeq・30字まで）を [onnxruntime-web](https://onnxruntime.ai/) 1.20.1 で動かす | モデル約 36MB ＋ 実行環境約 11MB |
| （予備の OCR） | [Tesseract.js](https://github.com/naptha/tesseract.js) 5.1.1。縦書きは `jpn_vert`、横書きは `jpn`（英和・和英では `eng+jpn`）。NDLOCR-Lite が使えないときだけ | 本体約 4MB ＋ 言語ごとに約 2〜3MB |
| 単語の区切り・読みがな・基本形 | [kuromoji.js](https://github.com/takuyaa/kuromoji.js) 0.1.2（IPA 辞書） | 約 17MB |

- **初回だけ合わせて約 65MB** を読み込みます（起動したら裏で読み込みはじめ、カメラの下に進み具合を出します。Wi-Fi のある所で一度開いておくとよい）。
  NDLOCR-Lite のモデルは Cache Storage に保存し、次からはそこから読みます（2回目からの準備は1秒ほど）。ほかはブラウザのキャッシュを使います
- NDLOCR-Lite のモデルと `ndl-chars.json`（同じ版の `src/config/NDLmoji.yaml` の `charset_train`）は、
  コミット `e57f7c6` に固定しています。モデルは GitHub（raw.githubusercontent.com）から、実行環境・Tesseract・kuromoji は jsDelivr の CDN から読み込みます
- kuromoji を読み込めないときは、ブラウザの `Intl.Segmenter` で区切るだけにします（読みがなは出ません）
- 撮ったときは、画面の点線のあいだに写っている範囲だけを、カメラの元の解像度から **色のまま** 切り出します。
  NDLOCR-Lite には、それを縦書きなら左へ 90° 回して横にし、256×24 に縮めて渡します（NDLOCR-Lite の `parseq.py` と同じ。
  白黒に整えるとかえって崩れる）。Worker の中で動かすので、読み取りのあいだも画面は固まりません
- NDLOCR-Lite は、Tesseract が「所謂」→「所調」、「哲学」→「折学」と読み違えた本の写真も正しく読めます。
  Tesseract は「謂」のような常用漢字でない字が苦手で、ほかの候補にも出てきません
- 予備の Tesseract には、白黒にして影や照明のむらをならし（区画ごとの紙の明るさで割る）、濃淡を広げ、白い余白を付けてから渡します
- OCR は1行として読みます。複数行をまとめては読みません
- kuromoji の辞書の展開は重い（表でやると数秒画面が固まる）ので、Worker の中で読み込んで区切ります
- kuromoji（IPA 辞書）は「所謂」→「所／謂」、「卓越せる」→「卓／越せる」のように漢字の熟語を分けすぎることがあるので、
  ブラウザ内蔵の区切り（`Intl.Segmenter`。熟語に強く、活用する語には弱い）が漢字だけの1語とした所は1つにまとめます。
  数や接頭詞を含む所（第二）はまとめません。まとめた語の読みがなは、kuromoji がその語を知っているときと、
  2字以上の名詞と接尾語だけのとき（研究＋室）にだけ付けます（「所謂」に「ところいい」と付けないため）。辞書の画面では辞書の読みを出します
- 辞書の読み込みは、カメラの映像が映ってから始めます。カメラの下に「カメラを起動中…」「文字を読む準備中…」と出ます
- 省電力モードなどでカメラ映像の自動再生が止められたときは「カメラを映す」ボタンを出し、押したら映します

## うまく動かないとき

`https://ksa02g.github.io/DictionaryCam/?debug` で開くと、画面の上に動きの記録（カメラの起動・映像の大きさ・
辞書の読み込み・読み取った文字と時間・エラーなど）が出ます。記録をタップするとコピーできるので、貼り付けて調べられます。
いちばん上の行に出る版（例 `2026-11-17a`）で、新しい版が読み込まれているかも確かめられます
（GitHub Pages のページは 10 分ほどキャッシュされるので、push の直後は古い版のことがあります）。
文字の読み取りが NDLOCR-Lite と Tesseract のどちらだったかも、「撮影:」の行に出ます。

## 試しかた（PC）

カメラは `localhost` でも使えるので、リポジトリのルートで

```powershell
py -3 -m http.server 8765 --bind 127.0.0.1
```

を動かして `http://127.0.0.1:8765/camera-jisho/` を開きます。スマホで試すときは https で公開したページを開いてください。
